### `README.md` — أُعيدت كتابته كاملاً | rewritten

كان يفتتح بـ «The Internship Management System is a smart backend platform designed
to manage internship evaluations» ويُعدِّد ميزات منتج لم يعد قائماً، وجدولَ تقدّمٍ
يقول «مكتمل» عن أشياء لا وجود لها.

- الاسم والوصف والجمهور: أسطرلاب، لثلاث جهات يبذرها `tools/seed-tenants.js`.
- قسمٌ يُسمّي القدرات الحقيقيّة: تعدّد الجهات بترويسة `__tenant`، وبنك الأسئلة
  والمخطّطات والأوراق المسحوبة، والرابط بوصفه كامل بطاقة الممتحَن، والتصحيح الآليّ
  واليدويّ باستراتيجيّة لكلّ نوع، ومؤشّرات النزاهة بوصفها ملاحظات لا أحكاماً،
  وتحليل جودة الأسئلة، والاستيراد بالجملة للأشخاص وللأسئلة، وهويّة كلّ جهة.
- **قسم «ما لا تفعله المنصّة»** — جديد، وثلاثة أقسام فرعيّة: غير موجود أصلاً؛
  ويُحفَظ ولا يقرؤه شيء؛ وناقص نصفه. كلّ سطر فيه مُحقَّق بقراءة الشيفرة.
- الأدوار الخمسة، وجدول الشاشات بحُرّاسها، وفهرس الوثائق، ومذكّرة عن اسم المستودع
  الذي لم يُهاجَر.
- حُذف: جدول التقدّم، والخطوات القادمة، وقسم المساهمة، وقسم التواصل — كلّها كانت
  تصف مشروعاً آخر.

*Rewritten from the first line. Adds a **"What the product does not do"** section in
three parts — absent outright, saved and read by nothing, half-built — each line
traced to code that was read.*

### `requirements.md` — أُعيدت كتابته كاملاً | rewritten

كانت أربعةً وستّين سطراً تصف تسجيل مرشّح لوظيفة، ومشرفين، ولوحاتِ موارد بشريّة.

- أربعة عشر مجموعة متطلّبات وظيفيّة (`FR-1` … `FR-14`)، لكلٍّ **شاشتها ودورها

- سبعة متطلّبات غير وظيفيّة (`NFR-1` … `NFR-7`): العربيّة والاتّجاه، والأمن،
  والأداء تحت الحِمل بأرقام اختبار الحِمل الفعليّة، وإمكانيّة الوصول (جزئيّ، بلا
  ادّعاء معيار)، وقابليّة النشر، والاختبار (بما فيه ما لا تحرسه الاختبارات)،
  والصيانة.

### `DeveloperGuide.md` — أُعيد كتابته كاملاً | rewritten

كان يذكر أدواراً غير موجودة (`Supervisor`، `HR Manager`، `Candidate`) ووحداتٍ لا
وجود لها (`TrainingManagement`، `CandidateManagement`)، ولا يذكر الواجهة الأماميّة
ولا الحاويات ولا الأدوات.

- التشغيل المحلّيّ بالترتيب، والمفتاح الوحيد المطلوب ولماذا يرفض الخادم الإقلاع
  بدونه، وبذر البيانات.
- بنية الحلّ الفعليّة، والسياقات السبعة.
- **أين يُضاف كلّ شيء**: نوع سؤال، وشاشة، وصلاحيّة، وكيان — بالخطوات وبالمزالق.
- الاختبار: الطبقات الخمس، **وما لا تحرسه الاختبارات مكتوباً صراحةً**
  (`AddAlwaysAllowAuthorization`، وإيهام HTTP في مشروعَي المتصفّح، و`live` خارج
  التكامل المستمرّ).
- الأدوات الستّ في `tools/` والسؤال الذي تجيب عنه كلٌّ منها.
- مواضع التصادم المعروفة: تصادم الأسماء مع Bootstrap، وقاعدة عزل الأرقام، والسهام
  المعكوسة مرّتين، والإدخال بين السمة والدالّة، وتعطيل مُرشِّح الجهات.
